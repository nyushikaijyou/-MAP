# Security Policy

## Scope

This repository publishes a static website through GitHub Pages. It does not run PHP or other server-side application code as part of the published site. Client-side JavaScript, third-party browser libraries, external links, repository permissions, and the publishing workflow remain relevant security considerations.

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal information, or other sensitive information in a public issue.

If GitHub Private Vulnerability Reporting is enabled for this repository, use the repository's **Security** tab to report a vulnerability privately. Otherwise, contact the repository maintainer privately through an available GitHub contact method before disclosing technical details publicly.

## Response

Reports will be reviewed as time and access permit. Please include the affected page or file, impact, and safe reproduction steps. Do not assume a report is fixed until a correction and verification have been announced.
